# Spitz

A free, open-source chess workspace for Linux desktops (GPL-3.0-or-later).

Spitz is a **graphical interface, not an engine**: play, analyse, train, and manage your games with
the chess engines you run yourself — Stockfish first, anything UCI-compatible after it. It is
**local-only by design**: no accounts, no cloud, no telemetry; the program opens no network
connections. You bring your own PGN and EPD files, tablebases, and opening books.

Status: specification-first. What the product will do, down to budgets and file formats, lives in
[`openspec/`](openspec/README.md); the rules the project will not cross live in
[`docs/adr/`](docs/adr/). There is no downloadable app yet, and no screenshots yet — first-party
artwork lands with the UI milestone.
